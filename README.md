# موقع مسار — PATH

ملفات الموقع الجاهزة للنشر على GitHub Pages.

## النشر

1. أنشئ مستودعًا عامًا جديدًا باسم `masar-path` على GitHub.
2. ارفع محتويات هذا المجلد إلى جذر المستودع.
3. من **Settings → Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، وبعدها اضغط **Save**.
4. سيظهر رابط الموقع في صفحة Pages بعد اكتمال النشر.

الصفحة تستخدم صورًا محلية مرفقة في هذا المجلد؛ ارفعها مع `index.html` كي تظهر بشكل صحيح.
